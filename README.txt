GOVERNMENT ITI RAMBAN — WEBSITE STARTER

Included:
- index.html: responsive public-facing website prototype
- Mobile navigation and demo enquiry form
- Sections for About, Trades, Admissions, Notices, Apprenticeship, Gallery and Contact

IMPORTANT:
This is a front-end starter/prototype. It does not contain a real admin dashboard, secure login, database, or working enquiry submission. The enquiry form only displays a demo confirmation and does not send/store data.
Before launch:
1. Replace sample content with verified and approved institute information.
2. Add approved photos, notices and actual trade details.
3. Confirm official contact details and obtain institute approval.
4. Build the admin backend and student authentication as a separate secure phase. Do not collect sensitive student information in this static prototype.

Preview:
Open index.html in a browser. To publish, upload it to a hosting provider such as GitHub Pages. Public GitHub repositories can be used with GitHub Pages on the free plan; follow the provider's current setup instructions.
